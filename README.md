# AI Diff Editor

A simple and intuitive diff editor designed specifically for working with AI coding assistants.

## The Problem
When working with AI, it can sometimes be difficult to understand the exact changes the AI made to your code. 
- Some AI tools don't show diffs properly.
- They might lack clear inline code diffs (unlike Antigravity or GitHub Copilot) for comprehensible changes.
- If you already had uncommitted changes before the AI modified your code, it becomes confusing to separate your changes from the AI's latest edits.

## The Solution
This tool introduces a simple **Tracking Button**. 

### How to use it:
1. **Click the Tracking Button**: Before you ask the AI to make changes, click the tracking button to mark your current code state.
2. **Let AI do its work**: Allow the AI to generate and apply its code changes.
3. **View the Diff**: The editor will cleanly show you exactly what the AI changed since you started tracking, making the AI's contributions 100% comprehensible.

## Features
- **Clear Inline Diffs**: Easily understand what lines were added, modified, or removed.
- **Isolate AI Changes**: Never get confused between your previous work and the AI's latest output.
- **Simple for Everyone**: Designed to be lightweight and straightforward, no complex setup required.
